**왜 지금**: PR #136 의 `/api/track?source=whale_tg` 는 *클릭* 만 측정 (실제 join 까지 도달했는지 모름). Telegram bot deep link 는 funnel 의 다음 step (실제 봇과 인터랙트 시작) 까지 측정 → conversion 곡선 가시화. 14 일 측정 후 *click → join conversion* 가 N% 미만이면 CTA 카피·위치 조정 신호.

**도입 비용**: 봇이 이미 있음 (`TELEGRAM_BOT_TOKEN` env). `/start` 핸들러 추가 + `WhaleFollow.astro` Telegram 링크를 `t.me/econpedia_bot?start=whale_tg` 로 교체. 약 1 sprint. **이번 사이클 다음 weekly 후보**.

**위험**: 봇이 채널 join 을 자동으로 못 함 (Telegram 정책) → 봇이 안내 메시지로 채널 링크를 보내고 사용자가 다시 클릭. friction +1 step. 측정 가치 vs friction trade-off.
