## 1. RSS-to-Telegram bridge (IFTTT / RSSHub / n8n) — W3 distribution 채택 검증

**무엇**: 오늘 머지된 `/whale/rss.xml` (PR #125) 를 IFTTT 또는 RSSHub 같은 무료 aggregator 에 등록해 외부 Telegram 채널 (e.g. r/Stocks Telegram 미러, /r/wallstreetbets Telegram 미러) 에 자동 포워딩. 즉, 우리 RSS 가 backlinks·neutral pull 채널 1 개를 즉시 확보하는지 14 일 측정.

**왜 지금**: W3 distribution wedge 의 "blocked_real_users" 상태. RSS endpoint 가 막 생겼지만 *aggregator 가 stumble across* 하기까지 평균 4-6 주. 사용자가 직접 1 개 등록하면 → measurement 시간 단축 + zero-cost. 매주 1 명만 유입돼도 8 / 일 baseline 대비 +12.5 % WoW.

**도입 비용**: 코드 0. 사용자가 IFTTT 무료 계정 1 개 + RSS feed URL 등록 (10 분). 또는 자체 호스팅 RSSHub docker container (OCI VM 동거, 무료).

**위험**: IFTTT 의 무료 플랜은 polling 1 시간 1 회 → 약속한 "30 초 안에 전달" SLA 깨짐. *외부 채널만* 으로 한정, Telegram 자체 알림은 기존 직접 push 유지. RSSHub 자체 호스팅이면 polling 주기 임의 설정 가능.
